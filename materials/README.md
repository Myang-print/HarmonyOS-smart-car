# Materials 资源索引

本目录保存开发环境、驱动、烧录调试工具、硬件资料和参考代码。大体积镜像与第三方安装包由 `.gitignore` 排除，Git 只跟踪各分类的 README。

| 分类 | 内容 |
| --- | --- |
| `hardware-docs/` | 小车原理图等硬件资料 |
| `drivers/` | CH340 等主机驱动 |
| `flashing-tools/` | HiBurn、ST-LINK Utility 等烧录工具 |
| `debugging-tools/` | 串口、MQTT、蓝牙调试工具 |
| `toolchains/` | Keil MDK、STM32 DFP 设备包及历史配套工具 |
| `environment-tools/` | VMware、RaiDrive 等宿主机工具 |
| `vm-images/` | OpenHarmony 开发虚拟机及快照 |
| `reference-code/` | Hi3861 支持包和 STM32 工程模板 |
| `archives/` | 历史压缩包、空占位目录和原 OpenHarmony 外层模板 |

第三方二进制不代表项目对其来源、许可证或安全性背书。运行前应核对来源、哈希、许可证与系统兼容性；优先使用芯片厂商或工具官方发布的新版安装包。
