# 硬件测试原始记录

该目录只保存用户从 UartAssistant 原样复制的日志或截图说明。不要在原始记录中人工修正、归纳或删除异常行。

命名规范：

```text
ITER<迭代>-<测试名>-<序号>.log
ITER<迭代>-<测试名>-<序号>.md
```

例如：`ITER0-infrared-levels-01.log`。

每个记录至少注明：

- 烧录的 Hi3861 目录/构建目标；
- 烧录的 STM32 工程（未烧录则写“保持原固件”）；
- `20_Iter1_Line_Follow_Diagnostic/` 当前实现为有限 FSM：正常循迹、`11` 短暂保持、原地扫描恢复和恢复失败停车；
- 各步骤的原始日志；
- 截图文件名（如果使用截图）。
