# Iter0 进入 Iter1 前置数据清单

本文件定义从 Iter0 进入 Iter1 的门禁。用户不需要解释传感器数值，只需提供照片、肉眼可见事实和操作单要求的原始日志。

## 必须提供

### 1. 小车底部照片

一张照片同时包含：

- 车头方向；
- 左右车轮；
- GPIO13 对应的左探头；
- GPIO14 对应的右探头；
- 两个探头与车体中心线的相对位置；
- 探头离地高度，能估计即可。

最好把小车放在一段直线黑胶带上拍摄，使黑线、两侧白色包边和两个探头的相对位置同时可见。

### 2. 赛道照片或手绘图

必须能看见或标注：

- 起点；
- 普通直线；
- 左岔路；
- 右岔路；
- 十字路口（如果存在）；
- 死胡同；
- 终点；
- 黑胶带路线和两侧白色包边。

手绘图不要求比例准确，但要标出行驶方向和每种路口的大致形状。

### 3. 传感器原始日志

使用 `TEST-INSTRUCTIONS.md` 的诊断固件，至少提供以下位置的连续日志：

- 两个探头都在白色道路包边；
- 两个探头都在黑胶带上；
- 左探头在黑胶带、右探头在白色包边；
- 左探头在白色包边、右探头在黑胶带；
- 黑胶带位于两个探头之间；
- 两个探头都在白色围边胶带（如果可操作）。

每个位置保持约 3 秒，反馈连续约 20 行 `ITER0,SENSOR` 日志即可。日志前写位置编号，不需要解释 `0/1`。

### 4. 终点图案

起点和终点都是完整“干”字型标记：纵向黑线连续通过，两条横向黑线之间有白色间隔。照片或手绘图需要标注其在整条赛道中的位置和行驶方向；程序不能靠单独一条横线判定起点或终点。

## 建议提供

用直尺测量，近似值即可：

- 黑胶带宽度；
- 两侧白色包边宽度；
- 两个探头中心之间的距离；
- 探头离地高度；
- 小车左右轮中心间距；
- 直线、转弯和路口的最小尺寸。

如果无法测量，照片中放一把尺子也可以，不需要读取具体数值。

## 需要观察但不需要判断

在后续单步运动测试中，用户只反馈以下肉眼事实：

- 车轮是否转动；
- 小车是否明显前进或后退；
- 左转/右转动作是否发生；
- 停车命令后是否停止；
- 日志是否清晰；
- 是否出现发热、异味、异常声音或无法停止。

用户不需要判断轮子方向是否正确，开发者会结合日志和操作步骤判读。

## 进入 Iter1 的判定条件

以下条件全部满足后，才能开始正式循迹代码：

- [ ] 已确认 GPIO13/14 与左右探头的对应关系；
- [x] 已确认当前硬件的 `0`/`1` 电平语义；
- [x] 已确认黑胶带位于两个探头之间时的实际组合；
- [x] 已确认小车底部探头布局（整体横向宽度略大于中间黑胶带）；
- [x] 已确认至少一种可靠的终点判定方法：完整“干”字型标记，起点/终点通过运行阶段区分；
- [x] 已获得真正的死路单横带时序样本；
- [x] 已获得合法左支路和合法右支路样本；
- [x] 已确认主车控链路的烧录配对关系：Hi3861 UART2/GPIO11 → STM32 PA10，前后左右动作和停车均已实车确认；
- [x] 已确认 STM32 2 秒失联自动停车：单帧前进后静默 4 秒，约 2 秒后肉眼停车；
- [x] 已确认本次赛道固定路线：第一个 Y 字岔路左侧、第二个 Y 字岔路右侧；
- [x] 主机协议测试通过；
- [x] 诊断固件不会驱动电机；
- 低速架空循迹诊断：修正版状态映射待重新测试（`00` 前进，短时 `11` 保持，持续 `11` 停车）；
- [ ] 普通直线黑胶带落地低速循迹；

## 不能据此进入 Iter1 的情况

- 只有一张未标注步骤的日志截图；
- 只知道 `L/R` 数值，但不知道探头相对黑线的位置；
- 没有终点图案或路线结束规则；
- 未确认左转和右转的实际运动方向；
- 用旧 HEX 或不确定构建目标烧录；
- 同时启用多个占用 UART2 或传感器 GPIO 的 Feature。
