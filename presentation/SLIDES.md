# Slides 提纲

## 1. 封面

- HarmonyOS 智能小车实训汇报
- 双控制器协同、闭环控制与自主循迹
- 姓名、班级、指导教师、日期

## 2. 双控制器系统架构

- Hi3861：传感器、任务调度、行为决策
- STM32：协议解析、编码器 PI、电机执行
- 串口传递左右轮速度
- 上电、非法输入、通信失联均停车

## 3. 开发路线与成果

```text
基础外设 → 电机执行 → 编码器闭环 → 双芯片联调 → 红外循迹
```

- 左右轮独立速度控制
- 前进、后退、差速转向、停车
- 约 2 秒通信失联停车

## 4. 循迹实验与迭代

- 居中：两轮同速
- 左偏、右偏：差速修正
- 读取失败：立即停车
- 原地扫描恢复不稳定，改为前进差速修正
- 特殊标记需要连续采样与状态判断

## 5. 固定赛道控制逻辑

```text
起点 → 循迹 → 岔路选向 → 死路掉头 → 路径回退 → 终点停车
```

- 第一个 Y 字岔路选左，第二个选右
- 记录岔路顺序与已选路径
- 转向和回退设置动作超时

- 学习识读电路图与元件图
- 掌握分层验证的开发流程
- 将 Git 融入日常开发
- 主动修改参数，理解原理与设计方法
