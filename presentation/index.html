BLUETOOTH CONTROL

蓝牙控制小车的实现

有效指令

统一大小写和格式，映射为前进、后退、转向或停车意图

持续按键

周期刷新当前目标，避免单次数据丢失造成动作中断

连续切换

最新有效指令覆盖旧目标，减少动作排队带来的延迟

未知字符

拒绝执行无法识别的数据，并回到安全动作

数据不完整

等待完整消息或重新同步，不把半条消息当作命令

通信中断

超过限定时间未收到有效更新，底层主动停车

接收输入　→　校验与解析　→　动作映射　→　周期发送　→　超时保护
LINE FOLLOWING

循迹小车的实现

稳定居中

左右轮保持相近目标速度，持续沿参考线前进

轻微偏移

根据偏移方向进行小幅差速修正，避免过度摆动

明显偏移

增大修正量，同时限制变化速度，保持运动连续

交叉或宽线

结合进入顺序、持续时间和当前状态判断特殊事件

短暂丢线

参考最近方向进行有限恢复，超时后停止搜索

传感器异常

过滤抖动并检测无效读数，无法判断时立即停车

连续采样　→　滤波消抖　→　状态分类　→　差速控制　→　恢复或停车
