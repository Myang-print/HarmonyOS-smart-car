# Iter1 直线循迹：全前进边缘跟随

上一版原地扫描恢复方案已宣布失败，原因是实际出现反向移动、不连续原地转圈，并且未可靠恢复路径。本版完全取消反向和原地旋转。

## 算法

```text
00 -> 前进
10 -> 前进中的左修正：左轮慢、右轮快
01 -> 前进中的右修正：左轮快、右轮慢
11 -> 保持最近一次前进命令；没有历史时前进
传感器读取失败 -> 停车
```

所有运动命令的两个轮子方向均为正转：

```text
不会发送反向帧
不会发送原地旋转帧
不会因 11 自动停车
```

该方案的目标是避免车辆在单探头越界或双高状态下停死，通过持续向前的边缘跟随离开局部异常区域。它不宣称已经解决最终赛道，也不处理岔路、死路和终点。

速度：

```text
直行：100 / 100
左修正：45 / 100
右修正：100 / 45
```
