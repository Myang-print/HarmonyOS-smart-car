# Hi3861 → STM32 轨迹控制

当前V5程序使用单一路径线程，每500ms刷新一次双轮命令，依次验证前进、停止、左转、右转和后退。配对固件为 `src/stm32/7_串口通信`。

## 接口协议

- GPIO11/UART2 TX → STM32 PA10/USART1 RX；两板共地。
- 115200-8-N-1，3.3V TTL。
- 6字节帧：`FC 左方向 左速度 右方向 右速度 FD`。
- 方向0为正转、1为反转，速度字节范围0~250。
- STM32超过2秒未收到合法帧会停车。

当前关键帧：前进 `FC 00 FA 00 FA FD`，后退 `FC 01 FA 01 FA FD`，左转 `FC 01 3C 00 3C FD`，右转 `FC 00 3C 01 3C FD`，停止 `FC 00 00 00 00 FD`。

V5路径为：前进2秒 → 左转0.75秒 → 前进2秒 → 右转0.75秒 → 后退2秒 → 左转0.75秒 → 后退2秒 → 右转0.75秒；每个动作之间停车1秒。
