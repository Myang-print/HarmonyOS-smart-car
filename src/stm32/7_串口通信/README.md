# Hi3861双轮速度控制接收端

该工程通过USART1接收Hi3861的左右轮速度，执行50ms编码器PI闭环，并用WS2812显示通信与运动状态。配对发送端为 `src/harmony/12.0_UART_Correspondence`。

## 接线与协议

- Hi3861 GPIO11/UART2 TX → STM32 PA10/USART1 RX，两板共地，3.3V TTL。
- 115200-8-N-1。
- 帧：`FC 左方向 左速度 右方向 右速度 FD`。
- 方向0为正转、1为反转；速度字节范围0~250，名义值为rad/s的100倍。
- 2秒无合法帧自动停车；发送端当前每500ms刷新一次。

速度上限低于帧头 `0xFC`，因此解析器可在任意位置用帧头重新同步。当前底盘对遥控速度应用5/2巡航增益，使250命令接近140编码器脉冲/50ms；这是实车标定，不是通用物理换算。

## 常用帧

| 动作 | HEX帧 |
| --- | --- |
| 高速前进 | `FC 00 FA 00 FA FD` |
| 高速后退 | `FC 01 FA 01 FA FD` |
| 原地左转 | `FC 01 3C 00 3C FD` |
| 原地右转 | `FC 00 3C 01 3C FD` |
| 停止 | `FC 00 00 00 00 FD` |

## 灯光诊断

| 灯光 | 含义 |
| --- | --- |
| 蓝色慢闪 | 尚未收到合法帧 |
| 黄色短亮 | 收到字节但未组成合法帧，常见于误发ASCII |
| 紫色 | 方向、速度或帧尾非法 |
| 绿/红/蓝/橙常亮 | 前进/后退/左转/右转 |
| 白色常亮 | 合法停车 |
| 红色快闪 | 合法链路超过2秒未刷新，已停车 |

串口助手必须选择HEX发送。USB-TTL TX与Hi3861 TX不得同时连接PA10；运动测试前先架空车轮。
